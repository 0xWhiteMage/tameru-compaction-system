# Tameru v1.4.1 — Better evidence retention for agent tool outputs

Tameru v1.4.1 improves the default local extraction path for saturated search results and noisy test failures, reduces omission-marker overhead and hardens recovery-store credential screening.

## Changes

- Preserve useful definitions and assignments in saturated grep/rg results; command flags such as `-n` no longer displace the searched name.
- Reduce long pytest captured sections while retaining boundary lines, recognised error fingerprints and warning-or-higher evidence. Blank lines no longer end a section prematurely.
- Share a caller-supplied gap marker across consecutive fully omitted grep files while preserving file headers.
- Add opt-in `inline_short_gaps=True`: keep a span when its omission marker would be at least as long. Grep/pytest cuts and `brief_context` honour `InliningGapMarker` too.
- Extend credential screening to Google API keys, Stripe live keys, bearer tokens and env/YAML assignments, while excluding common code expressions. The screen gates recovery persistence; it does not redact returned output or guarantee detection of every secret.
- Read CLI context and cache/recovery files as BOM-tolerant UTF-8; writes remain plain UTF-8.
- Align package, public API and engine receipt versions at 1.4.1; improve Hermes Ruff compatibility and refresh the README with practical use cases, a reproducible before/after example and visible version-labelled comparisons.
- Consolidate integration and advanced usage documentation; remove redundant integration folders and two unused scraped fixtures while retaining regression coverage and benchmark evidence.

## Verification

- 1,172 pytest tests passed, 3 skipped on Python 3.12.
- Production QA: 15/15 passed, including Japanese, Chinese and Arabic cases.
- Budget sweep: 15/15 clean at each tested ratio, with mean character savings of 77.3%, 68.4%, 61.2%, 41.5% and 24.9% at ratios 0.1, 0.2, 0.3, 0.5 and 0.7.
- Large synthetic document: 99.5% estimated token savings in 569.3 ms CPU time on the latest recorded runner. Timings depend on hardware and workload.
- Wheel/source builds and installed-wheel Python/CLI smoke checks passed.

Historical external comparisons remain v1.2.0/v1.3.0 measurements and were not rerun. The battery and sweep retain previous savings; affected grep/pytest cases intentionally change, so this is not a blanket byte-identical-output promise.

## Install

```bash
python -m pip install "git+https://github.com/0xWhiteMage/tameru-compaction-system.git@dbe40619b9ebcb1595269809dd9f963b1c246015"
```

Python 3.10+; no runtime dependencies or LLM calls for default extraction. `inline_short_gaps` remains off by default. Hermes users must update their separate plugin/vendor copy to receive the engine changes.

See the repository [README](https://github.com/0xWhiteMage/tameru-compaction-system/blob/main/README.md) and [CHANGELOG](https://github.com/0xWhiteMage/tameru-compaction-system/blob/main/CHANGELOG.md) for usage, recovery requirements and known limitations.
