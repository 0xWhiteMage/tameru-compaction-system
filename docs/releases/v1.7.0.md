# Tameru 1.7.0 candidate

Prepared 2026-11-05. Publication and the Hermes catalog update are separate steps.

## Changes

This candidate preserves whole selected records in SARIF, notebooks, Kubernetes
YAML, LCOV and JUnit reports. Notebook source and cell positions, coverage test
names and uncovered lines, diagnostic locations, Git commit identities and
retained patch structure remain associated with their records.

GraphQL error responses stay whole. JSON numbers that would change during
rewriting, ambiguous structures and malformed supported reports fail open.
Other fixes cover extended CJK and Hangul classification, Cargo failure output,
repeat-compression stability, disk mount paths containing spaces, Kubernetes
event headings, and recovery-store credential screening.

The corresponding Hermes plugin adds an activity table and original-output
viewer through the existing installation. Its extraction adds no LLM calls;
Hermes can still summarize with an LLM. Viewing an original in the UI does not
restore past model context, and original availability is bounded.

## Captured checks

The reviewed synthetic campaign evaluated 228 cases under hash seeds 0 and
12345. All returned successfully, with no recorded harness violations, equal
cross-seed output bytes and equal output after repeat compression.

All 224 required literal snippets across 172 cases were present. Nineteen
flagged transformation fixtures were reviewed from frozen inputs and outputs
for their specific record, numeric, count and historical-defect checks.
These are fixture results, not a general semantic-fidelity guarantee.

- [Campaign results and source hashes](../../benchmarks/redteam/reports/1.7.0/results.json)
- [Frozen transformation inputs/outputs](../../benchmarks/redteam/reports/1.7.0/transform-inspection.json)
- [Transformation review](../../benchmarks/redteam/reports/1.7.0/transform-review.json)
- [Reviewed runner](../../benchmarks/redteam/run_reviewed.py)

The existing production battery passed 15/15 cases. At each fixed-mode budget
ratio of 0.1, 0.2, 0.3, 0.5 and 0.7, the threshold sweep retained required
snippets without forbidden snippets in 15/15 cases; one case failed open at each
point. The [capture](../../benchmarks/release-1.7.0-gates.json) records those
operating points and source hashes. This is not an adaptive-policy evaluation.

The README's comparative latency/savings figures remain explicitly historical
1.6.0 measurements. This release does not claim a new comparative speed result.

## Hermes integration evidence

The [plugin's candidate report](https://github.com/0xWhiteMage/hermes-tameru-plugin/blob/main/docs/REPORT-1.7.0.md)
records the real-Hermes checks, packaging, Desktop DOM tests and 60 paired
scripted replays. The replay uses a fake summarizer and character-priced cache
simulation; it does not establish live-agent task accuracy or actual bills.
Live Electron validation remains pending.

Adaptive activation, task preferences and pressure-dependent retention remain
research proposals. They are not implemented in 1.7.0.
