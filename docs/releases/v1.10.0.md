# Tameru 1.10.0

Tagged 2026-11-23 at commit `d37fd43`. This is the first release line with protocol 3 and the worker-facing preset/data-file contract. The Hermes and DeepSeek Harness plugins now version independently; their `v0.1.0` tags vendor this release commit.

## What changed since 1.9.0

- **Protocol 3 and planning.** The worker protocol adds selector queries, cache statistics and a pure `plan()` operation. The engine's DeepSeek price profiles are shipped as hashed package data, so hosts can price cache rewrites without embedding their own copy of the tables.
- **Bounded large-input behaviour.** Inputs over 2,000,000 characters use streaming head/tail plus error-line sampling with reduced confidence; inputs over 8,000,000 characters fail open instead of being analysed unboundedly.
- **Content-keyed analysis caches.** Query-independent analyses are keyed by content digest and byte-capped rather than retaining whole input texts in long-lived host processes.
- **Preset-backed host integration.** The DeepSeek tool-result preset is part of the engine package, and the worker validates the public field list, ranges and closed enums in `tameru.protocol`.
- **Evidence and marker hardening.** Engine-emitted marker forms are registered centrally, forged caller markers are neutralised, structured-format restoration was tightened, and credential screening protects recovery storage.
- **Benchmark and replay evidence.** The release includes the sealed benchmark comparison, the S3 quality harness and host replay harnesses. The comparison corpus reports 25/25 required strings, 0 forbidden leaks, 16/16 clean cases, 80.2% mean characters saved and 5.05 ms median Tameru time; these are replay/per-output measurements, not a real-model quality or bill measurement.
- **Integration contract documentation.** The shared plugin bar specification, repository ownership guide and harness integration guide define one engine with independently versioned host plugins.
- **Operational hygiene.** The project is Apache-2.0, includes security-advisory fixes credited to `@joeynyc`, and reduces CLI startup cost through lazy imports.

## Compatibility and integration state

`ENGINE_VERSION` is `1.10.0`; the worker speaks protocol 3 and continues to accept protocol 1 and 2 requests within their documented field sets. Plugins vendor the engine byte for byte and expose the vendored commit separately from their own plugin version. Current plugin status is maintained in [docs/REPOSITORIES.md](../REPOSITORIES.md) rather than inferred from the engine version.
